# 링크콜 (zoom 저장소) — 1:1 화상통화·화면공유 웹앱

설치 없이 브라우저만으로 두 사람이 영상통화하고, 원하는 모니터나 창을 공유하는 1:1 통화 웹앱입니다.

- 수업용 배포 주소: https://linkcall.egibynote105g.workers.dev/
- 연결 준비 중인 도메인: https://zoom.codemaru.kr/ (GitHub Pages 화면 + Cloudflare TURN 발급. DNS와 Pages 설정을 마쳐야 열립니다)
- 기존 직접 연결 전용 주소: https://patrickdfg.github.io/zoom/
- 사용법·점검 순서: [USAGE.md](USAGE.md)
- TURN 서버 설정: [TURN_SETUP.md](TURN_SETUP.md)
- 작업 기록: [notes.md](notes.md)

## 지금 되는 것
- 1:1 카메라 영상과 양방향 음성 통화
- 관리자(구글 로그인)가 **1~8번 방**을 열고 상대방은 방 번호만 누르거나 `?room=3` 주소로 입장. 열린 방 표시는 관리자 화면에만 나옵니다.
- 관리자는 **6자리 임시 방**과 초대 링크도 만들 수 있습니다. 예전 24자리 링크도 그대로 들어갈 수 있습니다.
- 모니터 1, 모니터 2 또는 창 하나를 골라서 공유하고, 공유를 끊지 않고 **다른 화면으로 바꾸기**
- 통화 화면은 검은 배경 화상회의 배치입니다(가운데 상대 영상, 오른쪽 위 내 화면, 아래 도구 막대: 오디오·비디오·채팅·공유·원격제어·더 보기·종료).
- 보는 쪽 화면 기능: **크게 보기**(두 번 누르기), **휠·버튼으로 최대 400%까지 확대**, 끌어서 이동, 전체화면
- 상대 카메라를 다른 프로그램 위에 **작은 창(Picture-in-Picture)**으로 띄우기. 모니터가 하나뿐인 사람은 공유를 시작할 때 자동으로 시도합니다.
- 채팅, 10MB 이하 파일 전송, 화질·음질 선택, 연결이 잠깐 끊기면 자동 재연결
- **원격제어**: Google 크롬 원격 데스크톱을 연결해 주는 안내와 버튼. 12자리 지원 코드를 채팅으로 보내면 상대방이 한 번 눌러 바로 접속할 수 있습니다.

## 기술 구성
- React 18 (CDN UMD) + CSS. 빌드 없이 정적 파일로 실행됩니다.
- WebRTC는 PeerJS 1.5.5와 무료 PeerServer Cloud로 연결합니다.
- `main`에 푸시하면 Cloudflare Workers Free와 기존 GitHub Pages에 자동 배포됩니다. TURN 중계(Metered 무료)는 관리자와 상대방 모두 비밀번호 없이 받습니다(IP별 분당 10회 제한).

## 한계
- 웹페이지만으로는 상대 Windows의 마우스·키보드를 직접 조작할 수 없습니다. 원격제어는 크롬 원격 데스크톱에 맡깁니다.
- 관리자 확인은 화면에서만 합니다. 앱 코드를 아는 사람은 관리자보다 먼저 같은 번호의 방을 열 수 있습니다. 관리자가 방을 열 때 「이미 열려 있습니다」가 나오면 다른 번호를 쓰세요.
- 방 번호나 코드를 아는 사람은 누구나 들어올 수 있습니다. 방은 먼저 들어온 한 사람만 받습니다. 초대 링크는 믿을 수 있는 사람에게만 보내세요.
- 공개 무료 연결 서버를 쓰기 때문에 가용성을 보장하지 않습니다. Metered 무료 TURN은 월 500MB이며 한도 소진 시 다음 갱신일까지 중지됩니다. 직접 연결 통화는 이 용량을 쓰지 않습니다. [무료 구성과 한도](TURN_SETUP.md)를 확인하세요.

# Zoom — 1:1 화상통화·화면공유 웹앱

윈도우 컴퓨터 사이에서 간편하게 연결하는 1:1 통화 서비스입니다.

## 1차 개발 범위
- 브라우저에서 1:1 카메라 영상·양방향 음성 통화
- 사용자가 선택한 모니터(듀얼 모니터 포함) 또는 프로그램 창 공유
- 통화 도중 카메라 ↔ 화면 공유 전환
- 상대방의 공유 화면을 크게 보기
- 방 만들기와 초대 링크로 입장
- 마이크·카메라 켜기/끄기, 통화 종료

## 추후 개발 범위
- 상대방이 명시적으로 허용하는 원격 마우스·키보드 조작
- 윈도우 보조 프로그램 연동(브라우저만으로는 OS 전체 원격 조작 불가)
- 통화 안정화 및 품질 자동 조정

## 기술 방향
- 프런트엔드: React
- 음성·영상·화면 전송: WebRTC
- 방 연결 및 신호 교환: 별도 시그널링 서버가 필요하며 서비스 선택 전
- 배포: 정적 프런트엔드는 GitHub Pages 사용 가능. 통화 연결용 서버는 별도 운영 필요

> 현재 이 저장소는 프로젝트 방향을 기록한 초기 상태입니다. 작동하는 화상통화 앱은 아직 구현되지 않았습니다.
